# ShopEase AI Support Ticket System

ShopEase is a fictional e-commerce startup that receives customer
support tickets about account access, payments, orders, technical
errors, and feature requests.

This project explores how AI could help classify support tickets and
identify urgent issues. The AI would suggest a category and urgency
level, while a human employee would still make the final decision.
